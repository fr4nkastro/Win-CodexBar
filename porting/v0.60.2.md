## Worker ownership

Workers edit only their assigned tree and return evidence before integration.
Shared bridge or snapshot changes require a parent review of the exact missing
field and backward-compatibility impact.

| Lane | Scope | Branch |
| --- | --- | --- |
| Provider correctness | Provider credit/detail, Mistral, Alibaba/Qwen, Devin modules and tests | `port/agent-0602-providers` |
| Codex cost | Cost scanner, Codex history/pricing, workspace/cost tests | `port/agent-0602-cost` |
| Antigravity | Structured `agy` report recovery after the first lanes land | `port/micro-0.60.2-antigravity` |
| Claude swap | Retained usage and explicit repair semantics | `port/micro-0.60.2-claude-swap` |
| Shared adapter | Only exact shared fields proven necessary by workers | parent integration lane |
| UI parity | Read-only audit first; code only after a Windows reproduction | parent integration lane |

Credit values, percentages, and reset timestamps remain separate concepts.
Provider, account, workspace, credential, and session identity stays siloed.
New diagnostics must preserve the redaction guarantees from `#502`.

## Required evidence

Each port item records its immutable source commit and files, Windows analogue,
semantic translation, focused tests, and one of `PORT`, `ALREADY-COVERED`,
`PLATFORM-N/A`, or `DEFER-with-evidence`.

Focused checks include provider parser/fixture tests, cost rescans and cache
reload tests, Antigravity identity and managed-process tests, Claude timeout
and account-isolation tests, and `git diff --check`.

The final integration head requires:

```powershell
.\scripts\local-check.ps1 -Slice ci
pnpm --dir apps/desktop-tauri run tauri:build:debug
```

Any UI-affecting change also requires a fresh Windows build and CUA proof of
the changed surface. The CI mirror, Rust gates, frontend checks, fresh Tauri
debug build, and hardened Antigravity provider suite pass on the integrated
branch. No UI source changed in this port, so there is no changed surface
awaiting CUA proof. Release-only upstream commits remain outside the Windows
port by design.
